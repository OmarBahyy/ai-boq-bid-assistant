# AI BoQ & Bid Assistant (Challenge A)

Lightweight estimation and risk-triage assistant for German General Contractors / Bidders analyzing GAEB XML (`.X83`) Bills of Quantities (*Leistungsverzeichnisse*).

## Quick Start

```bash
pip install -r requirements.txt
export ANTHROPIC_API_KEY="sk-ant-your-key-here"
streamlit run app.py
```

You can also open `index.html` directly in a browser to preview the standalone front-end UI.
